## About

Machine learning researcher with **7+ years** of building end-to-end models in Python on multimodal biomedical and tabular data. My Ph.D. research at **Florida International University** develops interpretable AI for **Parkinson's disease**, linking genotype and phenotype so that model outputs support clinical decision-making in precision medicine. More recently I build **LLM agents** (Claude + MCP) that work through auditable, reproducible pipelines over biomedical knowledge graphs and omics data.

**Open to:** faculty positions and research or applied scientist roles in AI/ML, health AI, and data science, starting 2027.
